QADAM - Келечегиңе карай биринчи кадам!
QADAM - мектеп окуучуларына келечектеги кесибин тандоого жардам берген заманбап веб-платформа.

🎯 Максаты
Окуучуларга өзүнүн кызыгууларына жана жөндөмдөрүнө ылайыктуу кесипти табууга жардам берүү.

✨ Өзгөчөлүктөрү
🏠 Башкы бет - QADAM жөнүндө маалымат жана навигация
💼 Кесиптер - Ар кандай кесиптердин сүрөттөлүшү жана керектүү көндүмдөрү
📝 Кесип тандоо тести - 15 суроолуу интерактивдүү тест
🎓 Университеттер - Кыргызстандагы университеттер жана алардын багыттары
💡 Пайдалуу кеңештер - Кесип тандоо боюнча кеңештер
👤 Жеке кабинет - Колдонуучу профили жана тест жыйынтыктары
🎨 Дизайн
Заманбап жана жөнөкөй интерфейс
Көк, ак жана жеңил түстөр
Толук адаптивдүү дизайн (телефон, планшет, компьютер)
Жылмакай анимациялар жана өтмөлөр
🚀 Колдонуу
Орнотуу
Репозиторийди клондоңуз:
git clone https://github.com/yourusername/qadam.git
Долбоор папкасына кириңиз:
cd qadam
index.html файлын браузерде ачыңыз
